# Own Publication 시각화

논의용 HTML 목업이다. 실제 사이트 구현이 아니다.

파일: [`own-publication-visual.html`](own-publication-visual.html)

브라우저로 연다.

```bash
# 저장소 루트에서
python3 -m http.server 8765
# http://127.0.0.1:8765/docs/proposals/own-publication-visual.html
```

확인 포인트:

- 자체 사이트가 canonical publication
- Instagram 자동 배포는 중단, 웹 연결은 후순위
- Tistory는 유지하되 중심이 아님
- 홈 / 목록 / 기사는 장문 브리핑 출판물 톤
- 광고, 로그인, CMS, Analytics는 화면에 없음
