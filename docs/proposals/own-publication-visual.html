구현이 아니라 방향 확인용이다. 사이트 이름은 미정이다. Instagram 자동 배포는 중단하고, 웹 연결은 후순위다.

지금 그리는 구조

Tistory에 붙여넣는 시스템이 아니라, 승인된 글을 자체 사이트에 올리고 그 URL이 실제 글이 되는 시스템이다. 인스타 카드 자동 게시는 이번 그림의 중심이 아니다.

PRIMARY · 이번 단계

Own Website

Canonical publication. 장문 브리핑이 static HTML로 남고, sitemap / RSS / canonical URL을 갖는다. 독자가 읽는 곳은 여기다.

PAUSED · 후순위

Instagram

Graph API 자동 배포는 사실상 중단. 토큰 절차가 운영을 방해한다. 나중에 웹으로 올리는 연결은 가능하지만, V1 성공 조건이 아니다.

OPTIONAL · legacy

Tistory

제거하지 않는다. 다만 Playwright 자동화는 production-critical가 아니다. 사람이 붙여넣던 경로의 대체재가 자체 사이트다.

독자가 보는 것

  • 날짜가 보이는 브리핑 홈
  • 하루 1개 장문 기사
  • 이전 브리핑 목록

  • 승인된 글 → Markdown → 배포
  • 실제 URL 200 확인이 성공
  • 실패해도 글은 삭제하지 않음
  • CMS / Analytics / 수익화는 없음

시장 · 2026.08.27

반도체와 환율이 동시에 열린 하루

오늘의 경제 브리핑 · 약 6분 · 자동 발행 후 실제 URL에서 확인하는 대상이 이 페이지다.

오늘은 개별 뉴스를 나열하는 날보다, 두 재료가 같은 화면에 걸린 날이다. 반도체는 실적 기대를 다시 열고, 환율은 수입 물가와 수급 이야기를 같이 연다. 둘을 따로 보면 “좋은 뉴스 / 불안한 뉴스”로 갈리지만, 장전 브리핑에서는 연결을 먼저 적는다.

무슨 일이 있었나

수출 업종은 전일 해외 흐름과 실적 코멘트가 겹치며 위험선호를 되돌렸다. 동시에 원·달러는 방향이 닫히지 않은 채 수입 민감 업종의 해석 폭을 넓혔다. 정책 일정은 당일 재료라기보다 다음을 기다리는 변수로 남아 있다.

왜 중요한가

지수를 한 문장으로 말하면 “반도체가 상단을 받치고, 환율이 하단 해석을 흔든다”에 가깝다. 원문 헤드라인을 복제하지 않고, 출처에 있는 사실만 연결한다. 매수·매도·목표가 문장은 쓰지 않는다.

다음에 볼 것

실적 가이던스와 환율 변동성이 같은 주에 겹치는지가 관측 포인트다. 이 글은 사이트 홈의 오늘 자리, 목록, RSS, sitemap에 같은 URL로 연결된다.

출처
  • 반도체 실적 관련 보도
  • 원·달러 동향 관련 보도
  • 정책 일정 관련 보도

정보 안내용이며 투자 권유가 아닙니다. 로그인·댓글·광고는 이 페이지에 없다.

사람이 개입하지 않아야 하는 구간

성공 기준은 미디어 회사가 아니라 이 경로다. 승인된 글이 사이트 URL이 되고, 그 URL이 실제로 열리는지까지.

Collect→ Write→ Validate / Review→ Editor 승인→ WebsitePublisher→ Markdown→ Deploy→ URL 확인 · Instagram 웹 Analytics CMS

지금 증명할 것

  • 품질 게이트를 통과한 글만 공개된다
  • 홈 / 목록 / 기사 / RSS가 같은 글을 가리킨다
  • push 성공이 아니라 페이지 200이 성공이다
  • 실패해도 원문은 남는다

지금은 그리지 않는 것

  • Instagram Graph 자동 게시
  • 카드뉴스 캐러셀을 사이트의 주 경험으로 쓰는 일
  • WordPress 관리 화면
  • 광고, 구독, 전략 에이전트
